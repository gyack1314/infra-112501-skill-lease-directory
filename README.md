# 机器人技能调用的租约发现与任务中途接管

边缘厂区的训练服务分别发布能力和运行状态。调度台使用会话编号跟踪一组相互兼容的技能端点。示例事件由登记端、训练调度台、实例和运维控制台发出。

## 事件格式

每个 JSONL 文件是一段独立演练。每行含整数逻辑秒点 timestamp、事件名称 type 和对象 data。同一秒的行按文件顺序排列。时间从零起算。文件里的业务标识只用于建立输入之间的引用。所有场景均可在本地用合成角色重新运行。

- **register**　实例已经完成握手后的登记事实：站点、实例名、登记端授予的启动标识、技能、可服务租户、输入输出格式、校准标识、过期秒点和会话名额。演练记录以可比较整数表示同名实例的启动顺序。
- **health**　实例自身的健康上报：instance、boot 和 state。unknown 表示没有可用的探活证据。
- **renew**　同一启动进程申请将有效期延至 until。
- **reserve**　训练调度提出会话编号、租户、候选站点、技能序列、是否共享校准和最晚准备时间 ready_by。
- **start**　技能进程准备开始，引用会话号、序列中从 1 起算的段、出示的分配代次以及实例启动标识。分配代次是服务授予的业务标识，示例采用从 1 开始的数字。
- **checkpoint**　已开始实例提交检查点及其格式与校准，后续段引用检查点。不同 boot 的回执不可互换。
- **revoke**　运维撤销一个明确的实例启动标识。
- **reassign**　调度请求在已经交付的会话上重新取得下一段分配。
- **inspect**　值班台按会话查询当前状态及事件经过。
- **finish**　段执行端通过同样的分配身份上报已完成事实，最后一段完成后会话结束，后续重新领取视为新请求。
- **stop**　调度方取消会话。未开工名额可立即回收，正在执行的段不能在失去启动资格之前与接替者同时获准开始。

## 本地资料检查

需 Python 3.11。资料工具使用标准库，无需联网。下列命令读取事件文件并检查封装格式。

```sh
python3 trace_io.py data
python3 -m unittest -v
```

资料工具输出读取的文件、事件数量及首尾秒点。业务状态由使用该事件契约的服务维护。
